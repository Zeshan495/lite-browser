PIN Lock

Ask for a PIN every time LiteBrowser opens.

⚠️ How it protects you

If a wrong PIN is entered 2 times in a row, LiteBrowser erases everything: history, searches, sign-ins and cookies for every site, saved site data, open tabs, the downloads list and all settings (including the PIN). It then starts fresh, as if opened for the first time.

Downloaded files stay in your Downloads folder. A forgotten PIN can't be recovered.

DNS

DNS turns names like google.com into addresses. A slow or broken DNS server from your internet provider causes errors like DNS_PROBE_POSSIBLE.

Your Mac is using right now

Choose a provider

Your DNS servers

IP addresses (like 1.1.1.1) are applied to all your network connections when you click “Use on This Mac”. macOS asks for your password.
A secure DNS hostname (like dns.example.com, the kind Android calls “Private DNS”) uses encrypted DNS-over-TLS. Paste a full https://…/dns-query address to use DNS-over-HTTPS instead. macOS only accepts these through a profile, so LiteBrowser creates one and opens System Settings for you to approve it.
The “Fix DNS” button on error pages uses whatever you save here. “Reset to Automatic” undoes everything and goes back to your router's DNS.
